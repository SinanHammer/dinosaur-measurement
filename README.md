# 恐龙测量工具

一个基于Python开发的恐龙尺寸测量工具，支持多种测量模式和精确的尺寸计算。

## 功能特点

- **多种测量模式**：支持标准模式、快速模式和精确模式
- **分离式界面**：控制面板和图片测量窗口分离，操作更便捷
- **实时状态显示**：实时显示测量进度和操作状态
- **完整日志记录**：保留所有测量过程的详细日志
- **高兼容性**：基于PIL和Tkinter，避免OpenCV依赖问题

## 系统要求

- Python 3.6+
- Windows 10/11

```
pandas

```

```bash
pip install pandas pillow matplotlib numpy
```

## 使用方法

1. **运行程序**
   ```bash
   python "Dinosaur Measurement.py"
   ```

2. **操作步骤**
   - 选择包含恐龙的图片文件
   - 设置比例尺的实际长度（厘米）
   - 选择测量模式（模式一/模式二/模式三）
   - 点击"开始测量"，图片将在单独窗口显示
   - 在图片上点击两个点进行距离测量
   - 完成所有测量后保存结果

## 测量模式说明

- **模式一**：标准测量模式（5次测量）
  - 比例尺长度、头部长度、身体长度、头部宽度、身体宽度
- **模式二**：快速测量模式（3次测量）
  - 比例尺长度、头部长度、身体长度
- **模式三**：精确测量模式（5次测量，带校准）
  - 与模式一相同，但使用1.02校准因子

## 操作提示

- **左键点击**：添加测量点
- **右键点击**：撤销上一个点
- **重置按钮**：重新开始测量
- **保存按钮**：保存测量结果到CSV文件

## 界面布局

- **主窗口**（控制面板）：包含所有控制按钮和运行日志
- **图片窗口**：单独显示图片，用于测量操作
- **状态显示**：实时显示当前操作状态
- **运行日志**：显示详细的测量过程和结果
